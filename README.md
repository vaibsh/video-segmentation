# Video Segmentation

## About

This tool partitions video into coherent activity segments and describes what activity happens in each segment and the overall video. 

### What This Project Does

Given a video, the pipeline:  
1. Tracks objects/persons across frames
2. Extracts segmentation masks
3. Computes semantic embeddings
4. Generates features corresponding to each frame
5. Uses GPT to understand activity transitions
6. Produces temporally segmented activities with descriptions

Example:

```json
{
  "overall_video": "...",
  "segments": [
    {
      "start_frame": 0,
      "end_frame": 130,
      "activity": "...",
      "about": "..."
    }
  ]
}
```

### Running Locally

1. Clone Repository  
  `git clone https://github.com/vaibsh/video-segmentation.git`  
  `cd video-segmentation`  

2. Create Virtual Environment  
  `python3 -m venv venv`  
  `source venv/bin/activate`  

3. Install Requirements  
  `pip install -r requirements.txt`  

4. Add OpenAI API Key  
  Create a .env file:  
  OPENAI_API_KEY=your_api_key_here  

5. Run Pipeline  
  `python3 run_local.py \
    --video_file inputs/<your-video>.mp4 \
    --pkl_gz_file inputs/all_frames_data.pkl.gz`

## Architecture & Algorithms

 Following is a brief overview architecture / algorithms:  
 
 1. Preprocessing - Features are extracted from video using
    YOLO & BoTSORT - Object Detection & Tracking Objects across frames
    SAM2 - Generate accurate masks corresponding to objects across frames
    DINO v2 - Generate embeddings corresponding to the masked objects
    Bounding Boxes generated by YOLO and DINO v2 embeddings are fed to next step

 2. Bounding Boxes are used to generate center co-ordinates and understand motion dynamics. 
    These alongwith DINO v2 embeddings are the features created per frame. Semantic score is computed
    based on embeddings and motion dynamics. Gaussian filter is used to smoothen noisy frame-to-frame
    fluctuations, if any.

 4. Semantic Score is used to find peak frames, where activity / scene changes the most.
    These peak frames are sampled. Few (2 or 3) frames in the neighborhood of peak frames are sampled
    for understanding context around peak. In addition, few frames are sampled uniformly across the video
    to understand the general context. An upper limit is set on how many samples can be generated.
    These sampled frames are fed to GPT-4o instructing it to find semantic segments in the video and
    description of each segment. We refer to segments generated by GPT in this step as coarse segments.

 5. Segments generated by GPT are refined using the following method. Segments generates by GPT have boundary frames. 
    A small window (SEARCH_RADIUS) is chosen around these boundaries such that mid-points of the segments are not crossed
    to avoid overlap in refined segments. The small search window also preserves GPT’s high-level semantic understanding 
    while allowing local adjustment. Local Peaks are found in this window using previous method, and the peaks are ranked based
    on their semantic score and distance from GPT boundary. We refer to segments generated by GPT in this step as refined segments.

 6. For each segment in refined segments, samples are geneated using the previous method (peaks, neighborhood and uniform) and are fed
    to the GPT instructing it to understand each segment, generate a description of what happens in each segment and relate it to 
    what happens in the entire video. 

 7. Finally, the whole video is streamed highlighting which segment is being played alongwith frame boundaries and description
    of activity in each segment.
